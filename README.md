# HADARA Real Estate — الموقع الجديد

موقع إلكتروني احترافي لشركة **حضارة للتطوير العقاري (HADARA Real Estate)**، مبني بلغة
**TypeScript** و **CSS** خالص (بدون أي مكتبة تصميم جاهزة)، بأربع لغات: **الإنجليزية** (اللغة
الرئيسية)، **العربية** (بدعم كامل لـ RTL)، **الفرنسية**، و **الروسية**.

المحتوى والصور ومعلومات التواصل مأخوذة من موقع الشركة الحالي على Wix
(`byhadara.com`) عبر Wix API، ثم أُعيدت كتابتها وتنظيمها في تصميم جديد بالكامل.

## المزايا الأساسية

- **أربع لغات** مع مبدّل لغة في الهيدر، وتبديل تلقائي لاتجاه الصفحة (LTR/RTL).
- **قائمة "المشاريع"** في المنيو → بطاقات مشاريع، كل بطاقة فيها زر **"اكتشف المزيد"** → صفحة
  تفاصيل مشروع مستقلة (معرض صور + Lightbox + إحصائيات المشروع).
- **خانة بحث** في الهيدر تبحث في المشاريع وصفحات الموقع.
- **فورم تواصل** بحقول: الاسم، البريد الإلكتروني، رقم الهاتف (إلزامية) + الموضوع والرسالة
  (اختيارية)، مع تحقق (validation) فوري وعرض رسائل خطأ بكل اللغات.
- **أرقام وإحصائيات متحركة** (Stat Counters) في الصفحة الرئيسية وصفحة "من نحن" وصفحات
  المشاريع، مبنية على أرقام حقيقية (تاريخ التأسيس 2014، 5 مشاريع، عدد الوحدات، المساحات...).
- تصميم متجاوب بالكامل (Mobile / Tablet / Desktop).

## التقنيات

- **TypeScript** (بدون أي framework — DOM يُبنى برمجياً عبر دوال render).
- **Vite** كأداة بناء وتشغيل محلي.
- **CSS** خالص مقسّم حسب الاختصاص (`variables`, `base`, `layout`, `components`, `rtl`).
- توجيه (Routing) بسيط عبر الـ hash (`#/`, `#/projects`, `#/projects/:slug`, `#/about`,
  `#/citizenship`, `#/contact`) — يعمل على أي استضافة ثابتة (Static Hosting) بدون أي إعداد
  خاص على السيرفر.

## تشغيل المشروع محلياً

```bash
npm install
npm run dev       # تشغيل محلي على http://localhost:5173
npm run build     # بناء نسخة الإنتاج داخل مجلد dist/
npm run preview   # معاينة نسخة الإنتاج
```

## بنية المجلدات

```
src/
  components/   header, footer, project card, search, contact form, lightbox...
  data/         projects.ts — بيانات المشاريع الثابتة (صور، أرقام، مواقع)
  i18n/         en.json / ar.json / fr.json / ru.json — كل النصوص والترجمات
  pages/        home, projects, projectDetail, about, citizenship, contact, notFound
  styles/       ملفات CSS
  router.ts     التوجيه بين الصفحات
  main.ts       نقطة الدخول
```

## ملاحظات مهمّة قبل النشر (Production)

1. **الصور**: تُستخدم حالياً روابط صور حقيقية من Wix CDN
   (`static.wixstatic.com`) بدل رفعها من جديد، وهذا يعمل بشكل طبيعي في أي متصفح متصل
   بالإنترنت. يُفضّل مستقبلاً تحميل هذه الصور ونقلها إلى استضافة الموقع الجديد نفسه، حتى لا
   يبقى الموقع الجديد معتمداً على موقع Wix القديم.
2. **فورم التواصل**: يعمل حالياً عبر فتح تطبيق البريد الإلكتروني (`mailto:`) مع تعبئة الرسالة
   تلقائياً — وهذا يضمن عمل الفورم بدون أي سيرفر خلفي (Backend). لربط الفورم بشكل مباشر
   (بدون فتح برنامج البريد) يُنصح بربطه بخدمة مثل Formspree أو EmailJS أو دالة سيرفرلس
   خاصة بالشركة.
3. **الخريطة** في صفحة التواصل تستخدم OpenStreetMap (مجانية، بدون مفتاح API).
